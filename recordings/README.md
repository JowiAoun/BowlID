# Recordings

Put exported swing files here.

1. Open the app with `?who=yourname` at the end of the address.
2. Click "Practice lane" and bowl.
3. Click "Export recorded swings" on the front page.

Run `npm run evaluate` to see how well the matcher tells people apart on these files.

The `.json` files in this folder are ignored by git, so real swings stay on this machine.
